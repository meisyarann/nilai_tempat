3️⃣ Apa Beda "Nilai Tempat" dan "Nilai Angka"?

Banyak anak yang sering tertukar antara Nilai Tempat dan Nilai Angka. Yuk kita lihat perbedaannya dengan jelas:

🏠 Nilai Tempat

Adalah NAMA TEMPAT/POSISI dari angka tersebut.

Jawabannya selalu berupa KATA:
"Satuan", "Puluhan", "Ratusan", atau "Ribuan".

💰 Nilai Angka

Adalah HARGA / BESAR NILAI dari angka tersebut di posisinya.

Jawabannya selalu berupa BILANGAN:
contoh: 5, 50, 500, atau 5.000.
KLIK PADA SETIAP DIGIT BILANGAN DI BAWAH INI:
6 . 4 8 3
👉 Coba klik angka 6, 4, 8, atau 3 di atas!

6️⃣ Contoh Soal Cerita (Langkah demi Langkah)

Mari kita pelajari cara menyelesaikan soal cerita tentang nilai tempat tanpa takut bingung!

🍎 Cerita: Panen Apel Paman Budi

Paman Budi memanen 3.625 buah apel segar dari kebunnya di Malang. Paman Budi ingin mengemas apel-apel tersebut ke dalam kantong-kantong sesuai nilai tempatnya:
• Peti besar berisi 1.000 apel
• Kardus sedang berisi 100 apel
• Keranjang kecil berisi 10 apel
• Sisanya dibungkus plastik satuan
Berapa banyak peti besar, kardus sedang, keranjang kecil, dan plastik satuan yang dibutuhkan?

Langkah 1: Tuliskan Lambang Bilangannya

Bilangan apel yang dipanen adalah 3.625.

Langkah 2: Uraikan ke Dalam Nilai Tempat

• Angka 3 berada di tempat Ribuan (nilainya 3.000)
• Angka 6 berada di tempat Ratusan (nilainya 600)
• Angka 2 berada di tempat Puluhan (nilainya 20)
• Angka 5 berada di tempat Satuan (nilainya 5)

Langkah 3: Tarik Kesimpulan

Jadi, Paman Budi membutuhkan:
📦 3 Peti Besar (3 ribuan = 3.000 apel)
📦 6 Kardus Sedang (6 ratusan = 600 apel)
🧺 2 Keranjang Kecil (2 puluhan = 20 apel)
🛍️ 5 Plastik Satuan (5 satuan = 5 apel)

🏛️ 4 Rumah Nilai Tempat

Mulai dari kanan: Satuan (1), Puluhan (10), Ratusan (100), dan Ribuan (1.000).

🏠 Nilai Tempat vs Nilai Angka

Nilai Tempat berupa kata (contoh: Ratusan). Nilai Angka berupa bilangan (contoh: 300).

🧩 Bentuk Panjang (Dekomposisi)

Menguraikan bilangan menjadi penjumlahan nilai tiap digitnya (contoh: 4.521 = 4.000 + 500 + 20 + 1).

💡 Tanda Titik Pemisah Ribuan

Dalam kaidah Indonesia, tanda titik (.) digunakan untuk memisahkan setiap 3 digit ribuan (contoh: 7.325).

📊 Koneksi Langsung ke Google Sheets

Hubungkan media pembelajaran ini langsung dengan Google Spreadsheet Anda melalui Web App Google Apps Script. Setiap siswa login atau menyelesaikan kuis, baris baru otomatis bertambah di Spreadsheet!

Buka Google Sheets Baru ↗
🛠️ Panduan 3 Langkah Menghubungkan Google Spreadsheet:
  1. Buka spreadsheet baru di Google Sheets (sheets.new).
  2. Buka menu Ekstensi (Extensions) > Apps Script.
  3. Hapus semua isi kode di editor, tempel kode di bawah ini, lalu klik Terapkan (Deploy) > Penerapan baru (New deployment) > Pilih jenis Aplikasi web (Web app). Pada opsi Akses (Who has access), pilih Siapa saja (Anyone). Salin URL Web App dan tempel pada form di atas.
📄 Kode Google Apps Script (Code.gs): 
function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getActiveSheet();
  
  // Buat header jika sheet masih kosong
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Tanggal & Waktu", "Nama Siswa", "Kelas", "Aktivitas", "Skor Game 1 (Balok)", "Skor Game 2 (Cepat)", "Skor Game 3 (Pasang)", "Nilai Kuis", "Status KKTP"]);
    sheet.getRange(1, 1, 1, 9).setFontWeight("bold").setBackground("#D1FAE5");
    sheet.setFrozenRows(1);
  }
  
  var p = e.parameter || {};
  sheet.appendRow([
    p.timestamp || new Date().toLocaleString("id-ID"),
    p.nama || "-",
    p.kelas || "-",
    p.aktivitas || "Selesai Aktivitas",
    p.game1 || "0",
    p.game2 || "0",
    p.game3 || "0",
    p.nilaiKuis || "-",
    p.kktp || "-"
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({ status: "success", message: "Data tersimpan" }))
    .setMimeType(ContentService.MimeType.JSON);
}

function doGet(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getActiveSheet();
  var values = sheet.getDataRange().getValues();
  if (values.length <= 1) {
    return ContentService.createTextOutput(JSON.stringify({ status: "success", data: [] }))
      .setMimeType(ContentService.MimeType.JSON);
  }
  
  var list = [];
  for (var i = 1; i < values.length; i++) {
    var r = values[i];
    list.push({
      time: r[0] ? String(r[0]) : "-",
      nama: r[1] ? String(r[1]) : "-",
      kelas: r[2] ? String(r[2]) : "-",
      aktivitas: r[3] ? String(r[3]) : "-",
      game1: r[4] !== "" ? Number(r[4]) : 0,
      game2: r[5] !== "" ? Number(r[5]) : 0,
      game3: r[6] !== "" ? Number(r[6]) : 0,
      nilaiKuis: (r[7] !== "" && r[7] !== "-") ? Number(r[7]) : null,
      kktp: r[8] ? String(r[8]) : "-"
    });
  }
  
  return ContentService.createTextOutput(JSON.stringify({ status: "success", data: list }))
    .setMimeType(ContentService.MimeType.JSON);
}
